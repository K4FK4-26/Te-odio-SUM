    Gestion de Datos de Cursos

    1. Copiar Prompt para IA (CSV)

    Instrucciones para la IA:

    Proporciona el contenido en formato CSV (solo texto, sin cabecera) con las siguientes columnas en este orden: CICLO,CREDITOS,CURSO,TIPO,HRS,GR,DOCENTE,DIA1,INICIO1,FINAL1,DIA2,INICIO2,FINAL2. REGLAS: 1. CICLO: Usa "Ciclo 2", "Ciclo 3", "Ciclo 4", "Ciclo 5" o "Ciclo 6" 2. CREDITOS: Numero entero (2, 3, 4, etc.) 3. CURSO: El nombre completo del curso 4. TIPO: Solo "TEORIA" o "LABORATORIO" 5. HRS: Siempre 0 6. GR: Numero de grupo (01, 02, etc. para teoria; 00 para laboratorio) 7. DOCENTE: Nombre completo. Si no aparece, usa "No especificado" 8. DIA1, INICIO1, FINAL1: Dia y hora del primer horario 9. DIA2, INICIO2, FINAL2: Si tiene 2 dias, llenar; si no, dejar vacios (,,) IMPORTANTE: Solo responde con el CSV, sin texto adicional.
